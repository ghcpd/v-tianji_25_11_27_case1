# Test Suite

This test suite contains unit tests for the library components.

## Test Structure

### Test Files

1. **DataProcessor.test.ts** - Tests for `DataProcessor` class
2. **ApiClient.test.ts** - Tests for `ApiClient` class
3. **ValidationUtils.test.ts** - Tests for validation utilities

### Running Tests

```bash
# Install dependencies
npm install

# Run all tests
npm test

# Run tests in watch mode
npm run test:watch

# Generate coverage report
npm run test:coverage
```
